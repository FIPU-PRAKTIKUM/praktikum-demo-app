# monitoring/

**12. tjedan.** Observability za tvoju aplikaciju:

- Prometheus scrape konfiguracija ili `ServiceMonitor`,
- barem jedno alerting pravilo (npr. error rate ili latencija iznad praga),
- Grafana dashboard exportan kao JSON.

Definiraj barem jedan **SLI** i **SLO** za aplikaciju i zapiši ih ovdje.
