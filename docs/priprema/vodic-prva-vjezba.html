1Kolegij u dvije minute

Cijeli semestar radiš jedan individualni projekt: jednostavnu aplikaciju (API + baza + Redis) oko koje tjedan po tjedan gradiš infrastrukturu — skripte, Git workflow, Docker, Compose, CI/CD, Terraform, Ansible, Kubernetes, Helm, Argo CD, monitoring i security. Na kraju imaš aplikaciju koja se sama builda, testira i deploya na Kubernetes.

Ocjenjuje se infrastruktura, ne aplikacija. Aplikacija smije biti jednostavna i smije biti generirana uz AI. Odaberi jednostavnu — svaka dodatna komponenta je još jedan Dockerfile, servis i Deployment koji može puknuti.

3Računalo i instalacija alata prije vježbe

Računalo

  • min. 8 GB RAM-a, preporučeno 16 GB — u 11. i 12. tjednu istovremeno rade Kubernetes, Argo CD, Prometheus i tvoja aplikacija.
  • Ne treba cloud račun ni kartica, sve radi lokalno.
  • Računalo ne može? Javi se u 1. tjednu — radiš na laboratorijskom.

Što make check traži

git docker kubectl kind helm argocd ansible trivy python3

+ Docker daemon mora raditi (Docker Desktop pokrenut).
Uz to trebaju make i curl.

Windows — sve radiš u WSL2 (Ubuntu)

1
WSL2. PowerShell kao administrator, pa restart računala. Nakon restarta otvori „Ubuntu” i postavi korisničko ime i lozinku. 
wsl --install -d Ubuntu
2
Docker Desktop (docker.com). Settings → General: Use the WSL 2 based engine. Settings → Resources → WSL integration: uključi Ubuntu. Memoriju Dockeru daje WSL — po defaultu pola RAM-a (na laptopu s 8 GB to su 4 GB, dovoljno).
3
Alati u Ubuntu terminalu — nastavak je isti kao za Linux (ispod).

Repozitorij uvijek kloniraj u Linux home (~/), nikad u /mnt/c/... — na Windows disku je sve višestruko sporije, a skripte se lome zbog line endinga.

macOS

Instaliraj Docker Desktop (verzija za tvoj čip: Apple Silicon ili Intel) i Homebrew (brew.sh), zatim:

brew install git kubectl kind helm argocd ansible trivy python

make stiže s Apple Command Line Tools, koje instalacija Homebrewa postavi sama. U Docker Desktopu: Settings → Resources → Memory barem 4 GB.

Linux (i Ubuntu u WSL-u)

Osnovni paketi preko apt:

sudo apt update
sudo apt install -y git make curl build-essential python3 python3-pip python3-venv ansible

Za kubectl kind helm argocd trivy najjednostavnije je preko Homebrewa (radi i na Linuxu i u WSL-u). Instalacijska skripta na kraju ispiše Next steps — pokreni naredbe koje piše, pa:

/bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)"
# nakon "Next steps" (dodaje brew u PATH):
echo 'eval "$(/home/linuxbrew/.linuxbrew/bin/brew shellenv)"' >> ~/.bashrc && source ~/.bashrc
brew install kubectl kind helm argocd trivy

Na čistom Linuxu (bez Docker Desktopa) instaliraj Docker Engine po službenim uputama (docs.docker.com/engine/install) i dodaj se u grupu: sudo usermod -aG docker $USER, pa se odjavi i prijavi. Ako ti je draži drugi način instalacije alata (službeni binariji, apt repozitoriji), slobodno — bitno je da make check prođe.

4Git, SSH ključ i provjera okruženja

Tko si (jednom, na svom računalu — u WSL-u na Windowsu)

git config --global user.name "Ime Prezime"
git config --global user.email "tvoj@email.com"      # isti mail kao na GitHubu
git config --global init.defaultBranch main
git config --global pull.rebase false
git config --global core.autocrlf input              # WSL: bez Windows line endinga
git config --global --list                           # provjera

SSH ključ — da ne upisuješ lozinku pri svakom pushu

ssh-keygen -t ed25519 -C "tvoj@email.com"           # Enter, Enter, Enter
cat ~/.ssh/id_ed25519.pub                           # kopiraj cijeli red

GitHub → avatar → Settings → SSH and GPG keys → New SSH key → zalijepi. Zatim:

ssh -T git@github.com
# očekivano: Hi <username>! You've successfully authenticated...

Provjera da je sve spremno

Svoj repozitorij radimo zajedno na vježbi. Okruženje možeš provjeriti već sada na oglednom repozitoriju — u njemu su isti Makefile i skripta:

cd ~
git clone https://github.com/vanjaluk8/praktikum-demo-app.git
cd praktikum-demo-app
make check          # svaki alat [ok] + "Docker daemon radi" → "Sve je spremno."
make cluster-up     # diže lokalni Kubernetes (kind), ~1 min
kubectl get nodes   # jedan node u stanju Ready
make cluster-down   # obriši cluster, ne treba ti do 10. tjedna

Ako make check ne prođe, zapiši točno koji red je [--] i donesi to na vježbu (ili pitaj na forumu prije). Na vježbi rješavamo zapinjanja, ali ne stignemo instalirati WSL i Docker od nule za cijelu grupu.

5Što radimo na prvoj vježbi

Prvi tjedan radiš samo jednom. Cilj: od 2. tjedna imati okruženje koje radi i repozitorij u koji možeš predavati. Setup checklist se ne boduje, ali bez njega ne možeš predati nijedan lab.

1

make check i make cluster-up

Odabir aplikacije — rok kraj 2. tjedna

  • Minimum: API + baza (PostgreSQL) + Redis, /health koji provjerava obje veze, nekoliko testova i nešto mjerljivo za monitoring.
  • Tko prvi prijavi, taj dobije — dvoje ne mogu imati istu aplikaciju. Vlastiti prijedlog mora biti odobren do istog roka.
  • ★ aplikacije su najsigurniji izbor. Cijeli stack mora raditi s 4 GB RAM-a; arhitektura mora stati na jedan slajd.
  • Jezik i framework biraš sam. Frontend nije obavezan. Ako ti kod aplikacije stvarno ne ide, javi se do kraja 2. tjedna i dobit ćeš gotovu.
